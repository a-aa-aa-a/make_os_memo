第2章

OSとは

実際に使っているOSはどのように起動しているのか

この章では電源を入れてからOSが読み込まれるまでの流れをまとめます

目次

    1. OSとは何か

    OSとは何かざっくり説明します。

    OSとはアプリケーションなどのソフトウェアを動かすための機能を提供してくれるシステムソフトウェアのことです。

    具体的になOSを挙げると

    • Windows
    • MacOS
    • Linux

    などが挙げられます

    2. OSはどんな機能があるか

    OSの機能は以下のようなものが挙げられます。

    • メモリ管理
    • プロセス管理
    • ファイルシステム
    • ネットワーク
    • UI

    などが挙げられます

    3. OSの起動の流れ

    大まかな流れは以下の通りです。

    1. BIOS/UEFIが起動してUSB,SSD,HDDのどれかからブートローダーを読み込む
    2. ブートローダーがOSのプログラムを読み込んだり、機能を準備したりする
    3. OSのプログラムがRAMに読み込まれ
