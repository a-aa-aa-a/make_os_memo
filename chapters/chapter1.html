第1章

環境構築

この章では開発環境を構築する方法を説明します。

目次

    1. vscodeの導入

    Visual Studio Codeのホームページに行きインストールします。

    ほかのエディタが好きならなくてもいいです。

    vscode

    2. wslの導入

    VSCode上でCtrl + Shift + @ を押してターミナルを開きます

                wsl --version

    インストール出来たら起動します

                wsl

    3. アセンブラ、コンパイラなどの導入

    これからはwsl上でコマンドを実行します

                sudo apt install nasm gcc g++ make
